# Pixel Hangout 🏠✨ (เวอร์ชันมีเสียง/กล้อง)

ห้องพิกเซลน่ารักๆ สำหรับเพื่อน 2–8 คน: แต่งตัวละคร จองและแต่งโต๊ะทำงาน จัดห้อง เดินเล่น แชต ส่งอีโมต
และ **คุยเสียง/เปิดกล้อง** ได้ในตัว ใช้ได้ทั้งบนคอมและมือถือ (กด "เพิ่มลงหน้าจอหลัก" แล้วใช้เหมือนแอปได้)

## ฟีเจอร์
- **ตัวละครพิกเซล**: ผม 7 ทรง สีผม 10 สี เสื้อ 5 แบบ เครื่องประดับ 12 แบบ สัตว์เลี้ยงเดินตาม 5 ชนิด และปุ่มสุ่ม 🎲
- **โต๊ะทำงานของตัวเอง**: มีทั้งหมด 6 โต๊ะ จองแล้วแต่งได้ทั้งสีโต๊ะ ชุดคอม (โน้ตบุ๊ก จอคู่ CRT เกมมิ่ง RGB) สีเก้าอี้ ของบนโต๊ะ 12 อย่าง และพรมใต้โต๊ะ
- **จัดห้องร่วมกัน**: มีเฟอร์นิเจอร์ 17 แบบ ลาก เปลี่ยนสี หมุน หรือลบได้ เพื่อนเห็นของขยับทันที
- **มีชีวิตชีวา**: ท้องฟ้านอกหน้าต่างกับนาฬิกาเปลี่ยนตามเวลาจริง กลางคืนไฟจะเปิดเอง และมีปลาว่าย แมวหลับ ตู้เกมกะพริบ
- **คุยกัน**: แชต (เป็นบับเบิลเหนือหัว) อีโมต และสถานะ เช่น 💻 ทำงาน หรือ ☕ พักเบรก
- **เสียง/กล้อง**: Opus 128 kbps ตัดเสียงรบกวน มีวงเขียวตอนพูด และวิดีโอลอยเหนือหัว (แตะเพื่อดูเต็มจอ)
- **⚙️ ตั้งค่าเสียง**: เลือกไมค์/กล้อง/ลำโพงได้ มีแถบวัดเสียง และ **ฟังเสียงตัวเอง** (ปรับความดังได้ ฟังได้แม้ปิดไมค์กับเพื่อน) รวมถึงเปิด/ปิดระบบตัดเสียงรบกวนและเสียงสะท้อน
- **เดินง่าย**: แตะพื้นแล้วตัวละครหาทางเดินเอง แตะโซฟาหรือโต๊ะตัวเองเพื่อเดินไปนั่ง

## รันบนเครื่อง
```bash
npm install
npm start          # รวมไฟล์ใน src/ แล้วเปิดเซิร์ฟเวอร์
# เปิด http://localhost:3000
```

## เอาขึ้นเน็ตให้เพื่อนเข้า (ฟรี) — ตัวอย่าง Render
ไมค์และกล้องต้องเปิดผ่าน **https://** ซึ่งโฮสต์พวกนี้มีให้อัตโนมัติ
1. อัปโฟลเดอร์นี้ขึ้น GitHub (ไฟล์ `.gitignore` มีให้แล้ว)
2. ที่ render.com กด **New → Blueprint** แล้วเลือก repo นี้ (มีไฟล์ `render.yaml` ตั้งค่าให้ครบแล้ว)
3. หรือจะกด New → Web Service เองก็ได้ โดยตั้ง Build Command เป็น `npm install` และ Start Command เป็น `npm start`
4. ถ้าอยากล็อกห้อง ให้เพิ่ม Environment ชื่อ `ROOM_PASSWORD`
5. ได้ลิงก์ `https://xxxx.onrender.com` แล้วส่งให้เพื่อนได้เลย

> โฮสต์ฟรีส่วนใหญ่จะ "หลับ" เมื่อไม่มีคนใช้ ครั้งแรกที่เปิดอาจต้องรอประมาณหนึ่งนาที และข้อมูลห้อง (ไฟล์ใน `data/`) อาจรีเซ็ตเมื่อ deploy ใหม่ ถ้าอยากเก็บถาวร ให้ตั้ง `DATA_DIR` ไปยัง persistent disk
>
> ถ้าแค่อยากลองเร็วๆ ใช้ `cloudflared tunnel --url http://localhost:3000` ก็ได้ลิงก์ https ทันที

## ตั้งค่า
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | 3000 | พอร์ต |
| `ROOM_NAME` | Pixel Hangout | ชื่อห้อง |
| `ROOM_PASSWORD` | (ไม่มี) | รหัสผ่านห้อง |
| `MAX_USERS` | 8 | จำนวนคนสูงสุด (เสียงต่อตรงแบบ mesh เหมาะกับไม่เกินประมาณ 6 คน) |
| `DATA_DIR` | ./data | ที่เก็บห้อง/โต๊ะ/แชต |
| `TURN_URL` `TURN_USER` `TURN_PASS` | (ไม่มี) | TURN server สำหรับเน็ตที่ต่อเสียงตรงไม่ได้ |

## โครงสร้างโค้ด
```
src/sprites.js   พิกเซลอาร์ตทั้งหมด (วาดด้วยโค้ด ไม่มีไฟล์รูป): ตัวละคร สัตว์เลี้ยง เฟอร์นิเจอร์ โต๊ะ
src/world.js     แผนที่ห้อง พื้น/ผนัง หน้าต่างตามเวลา การชน และการหาเส้นทาง (A*)
src/net.js       ตัวเชื่อมต่อ 3 แบบ: ลิงก์ Claude / เซิร์ฟเวอร์นี้ (WebSocket) / เล่นคนเดียว
src/voice.js     WebRTC เสียง+กล้อง
src/main.js      ตัวเกม UI แชต การแต่งตัว แต่งโต๊ะ และจัดห้อง
build.js         รวมทุกไฟล์เป็น public/index.html (และ dist/pixel-hangout.html สำหรับลิงก์ Claude)
server.js        เซิร์ฟเวอร์ Node: หน้าเว็บ + WebSocket
```
หน้าเว็บชุดเดียวกันจะเลือกวิธีเชื่อมต่อเอง: ถ้าเปิดจากเซิร์ฟเวอร์นี้จะมีปุ่มไมค์/กล้อง ถ้าเปิดเป็นลิงก์บน claude.ai จะใช้ระบบห้องของ Claude แทน
